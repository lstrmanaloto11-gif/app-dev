# My Favorite Series: Stranger Things

This repository is part of my App Dev coursework. Below is some information about one of my favorite sci-fi series.

## 🎬 Overview
When a young boy vanishes, a small town uncovers a mystery involving secret experiments, terrifying supernatural forces, and one strange little girl.

### 🌟 Key Elements
* **Genre:** Sci-Fi, Horror, Drama
* **Creators:** The Duffer Brothers
* **Setting:** Hawkins, Indiana (1980s)

### 🍿 Top 3 Favorite Characters
1. **Eleven** - A girl with psychokinetic abilities.
2. **Dustin Henderson** - The highly intelligent and protective friend.
3. **Jim Hopper** - The dedicated chief of Hawkins Police.
